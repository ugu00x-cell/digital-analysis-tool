# 工程センサーデータ 異常検知ツール

製造ラインのセンサーデータ（温度・圧力・振動）から異常を自動検出するツールです。

**Isolation Forest（機械学習）** と **3σ法（統計的手法）** の2手法を並べて比較できるため、
「MLモデルと既存ルールの違いはどこか」をそのまま現場へのDX提案資料として使えます。

## 検知できる異常パターン

| 種類 | 説明 | 実例 |
|------|------|------|
| **スパイク異常** | 瞬間的な急上昇・急降下 | 電源ノイズ、衝突 |
| **ドリフト異常** | 値が時間とともに徐々にずれる | 工具摩耗、熱膨張 |
| **固着異常** | センサーが同じ値に張り付く | センサー故障、配線断線 |

## 使い方

### セットアップ

```bash
pip install -r requirements.txt
```

### サンプルデータで動かす（デフォルト）

```bash
python main.py
```

`output/` フォルダに結果が保存されます。

### 自分のCSVを使う

```bash
python main.py --input your_data.csv
```

**CSVフォーマット**（カラム順不問）:

```
timestamp,temperature,pressure,vibration
2024-01-01 00:00:00,80.3,5.1,0.51
2024-01-01 00:01:00,79.8,4.9,0.49
...
```

`is_anomaly` カラム（0/1）があれば精度評価（Precision / Recall）も自動で行います。

### 汚染率の調整

```bash
# 全データの10%が異常と想定する場合
python main.py --contamination 0.1
```

## 出力ファイル

| ファイル | 内容 |
|---------|------|
| `output/sensor_timeseries.png` | センサー別時系列グラフ（異常点をハイライト） |
| `output/comparison.png` | Isolation Forest vs 3σ法 の検知結果比較 |
| `output/result.csv` | 予測スコア・ラベルを付与した全データ |
| `output/sample_input.csv` | 使用したサンプルデータ（--input 省略時のみ） |

## 出力例

### センサー別時系列グラフ
- グレー点：正常
- 🟠 オレンジ：Isolation Forest のみが検知
- 🟣 紫：3σ法のみが検知
- 🔴 赤：**両手法が一致して検知（信頼度が高い異常）**
- 破線：3σ のしきい値（±3標準偏差）

## ディレクトリ構成

```
anomaly_detection/
├── data_generator.py   # サンプルデータ生成（正常 + 3種類の異常）
├── detector.py         # 異常検知ロジック（Isolation Forest / 3σ法）
├── visualizer.py       # 結果の可視化
├── main.py             # エントリポイント（CLI）
├── requirements.txt
└── output/             # 実行後に自動生成
```

## DX提案への活用

このツールは製造業のDX提案でそのままデモとして使えます。

- 「御社の設備センサーCSVを渡していただければ、このツールで異常の傾向を分析できます」
- 「3σ法で見えていなかった**ドリフト異常**を、機械学習で早期に検知できました」
- 「Precision / Recall のトレードオフを調整することで、誤報率と見逃し率のバランスを現場に合わせられます」
